# Météo du lycée

Écran météo (800 × 480) avec ses styles, et sa page de réglages.

- **Écran** : `index.html`
- **Réglages** : `admin.html` (on relie l'admin à l'écran avec le code affiché en bas de l'écran)

Météo : Open-Meteo · Radar : RainViewer · Relais admin ↔ écran : ntfy.sh

## Sur téléphone

Ouvre `admin.html` sur ton téléphone, puis « Ajouter à l'écran d'accueil » : l'admin s'ouvre comme une appli.
